⚙️ CONFIGURATION QUICK REFERENCE

Adjust Detection Sensitivity:

  Too many pivots?
  → Increase PivotMinDeviation (e.g., 0.0001 → 0.0005)
  → Increase PivotLeftBars/RightBars (e.g., 3 → 5)

  Too few pivots?
  → Decrease PivotMinDeviation (e.g., 0.0001 → 0.00005)
  → Decrease PivotLeftBars/RightBars (e.g., 3 → 2)

  Too many MAJOR classifications?
  → Increase HigherHighThreshold (e.g., 2.0 → 3.0)

Recommended Settings:

  Conservative (Few pivots):
    PivotLeftBars       = 5
    PivotMinDeviation   = 0.0005
    HigherHighThreshold = 3.0

  Balanced (Recommended):
    PivotLeftBars       = 3
    PivotMinDeviation   = 0.0001
    HigherHighThreshold = 2.0

  Sensitive (Many pivots):
    PivotLeftBars       = 2
    PivotMinDeviation   = 0.00005
    HigherHighThreshold = 1.5
