USAGE INSTRUCTIONS (QUICK REFERENCE)
================================================================================

COMPILE
1. Open MetaTrader 5
2. Tools → MetaEditor (F11)
3. File → Open → GonyTrendLineEAVisual.mq5
4. Press F5 to compile
5. Expected: "0 errors, 0 warnings"

TEST
1. View → Strategy Tester (Ctrl+R)
2. Select: GonyTrendLineEAVisual
3. Symbol: EURUSD (or preferred)
4. Period: H1 (1-hour)
5. Date Range: Last 1-2 weeks
6. Click START

OBSERVE
- Green downward arrows = Major swing highs
- Red upward arrows = Major swing lows
- Light green/coral = Minor swings
- Debug panel (top-left) = Detection statistics

TUNE (if needed)
1. Change PivotMinDeviation (too many/few pivots)
2. Change PivotLeftBars/RightBars (window size)
3. Change HigherHighThreshold (major/minor balance)
4. Run test again
5. Document final settings
